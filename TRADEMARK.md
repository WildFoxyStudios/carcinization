# Carcinization OS Trademark Policy

This document outlines the policy regarding the use of the Carcinization OS trademark owned by the Carcinization OS project. The purpose of this policy is to ensure that the Carcinization OS trademark is used correctly and consistently, maintaining the integrity and reputation of the Carcinization OS brand.

*Carcinization* takes its name from carcinization, the evolutionary process by which a lineage of species converges on the body plan of the crab. The trademark embodies that idea: many disparate projects settling into one common shape.

1. Usage of the Carcinization OS Trademark
    1. The Carcinization OS trademark includes, but is not limited to, the name "Carcinization OS", the Carcinization OS logo (the crab), and any associated symbols or designs.
    2. The Carcinization OS trademark may only be used in accordance with this policy. Unauthorized use of the trademark is prohibited.
2. Permissible Use
    1. Community Projects: Community projects may use the Carcinization OS trademark to refer to the operating system, provided that such use is not misleading and does not imply endorsement by the Carcinization OS project without explicit permission.
    2. Educational and Informational Use: The Carcinization OS trademark may be used in educational and informational materials, including books, websites, and articles, to refer to the operating system, provided that such use complies with the guidelines set forth in this policy.
    3. Marketing and Promotional Use: Partners and affiliates of the Carcinization OS project may use the Carcinization OS trademark in marketing and promotional materials with prior written consent from the Carcinization OS project.
3. Prohibited Use
    1. Misrepresentation: The Carcinization OS trademark must not be used in a way that misrepresents or implies false association with, endorsement by, or sponsorship from the Carcinization OS project.
    2. Modification: The Carcinization OS trademark must not be altered, modified, or used as part of another trademark or logo without prior written permission from the Carcinization OS project.
    3. Merchandising: The Carcinization OS trademark must not be used on merchandise (e.g., T-shirts, mugs) for commercial purposes without explicit authorization from the Carcinization OS project.
4. Logo Usage Guidelines
    1. The Carcinization OS logo must be used as provided by the Carcinization OS project without any modifications. This includes maintaining the logo’s colors, proportions, and overall design.
    2. The Carcinization OS logo must be displayed in a manner that is clear and legible. Sufficient clear space should be maintained around the logo to ensure it is not crowded by other visual elements.
    3. The Carcinization OS name should be identified as a trademark using the “™” symbol.
    4. The master artwork is distributed in two forms: `logos/carcinization/logo.svg` (scalable vector) and `logos/carcinization/logo.png` (raster). Prefer the vector form for print and large-format use.
5. Official Carcinization OS Software
    1. Software hosted at [the Carcinization OS GitLab group](https://gitlab.redox-os.org/redox-os/) is considered official Carcinization OS software. Only software that has been approved by the Carcinization OS project is permitted to use the Carcinization OS trademarks to refer to itself. Software that is official Carcinization OS software may use the “carcinization-os-” package namespace and “org.carcinization_os.” prefixed reverse-DNS ID. Other software should avoid using these prefixes.
    2. Third-party software that integrates with or extend the Carcinization OS operating system must not use the Carcinization OS trademark in a way that implies official status or endorsement without prior approval from the Carcinization OS project. Third-party developers are encouraged to use the "carcinization-os-ext-" package namespace. This software may be described as "for the Carcinization OS™ operating system".
    3. Third-party software may request inclusion as official Carcinization OS software. To request inclusion, please contact the Carcinization OS project at trademark@redox-os.org.
6. Request for Permission
    1. To request permission for uses of the Carcinization OS trademark not covered by this policy, please contact the Carcinization OS project at trademark@redox-os.org.
    2. All requests will be reviewed on a case-by-case basis, and the Carcinization OS project reserves the right to grant or deny permission at its sole discretion.
7. Enforcement
    1. The Carcinization OS project reserves the right to take appropriate legal action against any unauthorized use of the Carcinization OS trademark.
    2. The Carcinization OS project may, at its discretion, require the cessation of use of the Carcinization OS trademark by any party that fails to comply with this policy.
